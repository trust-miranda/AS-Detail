# AS Detail

Source code for [asdetail.pt](https://asdetail.pt).

## Run locally

```bash
npm install
npm run dev
```

Vercel normally serves the site at `http://localhost:3000`.

## Deploy to production

```bash
npm run deploy
```

The site is a static single-page website. The main files are `index.html`, `styles.css` and `script.js`. Before-and-after images are stored in `asdetail-site/`.
